Table

Data table that always renders from data plus el-table-column children. Cells stringify row[name] unless a column provides elTableCell. You sort and page the array; the table does not. Pair with Pagination in the footer.

Add to your project: npx @ng-elemental/cli add table (requires icon)

Installation

Usage

Pass the visible rows in [data]. Declare columns with name (the field key) and optional label. Add <ng-template elTableCell let-row> only on columns that need a widget. Header templates use elTableHeader. Project <el-pagination> as a child for the footer.

Standards and checks

  • Native table semantics with <th scope="col"> headers.
  • Sort buttons expose aria-sort; expand toggles use aria-expanded.
  • Name the grid with caption or ariaLabel.
  • Empty and loading states replace body content — no silent blank tables.
