Select

Combobox with an open panel slot. Use el-select-item for selectable rows (custom content allowed), and optionally ng-template elSelectValue for the closed trigger.

Add to your project: npx @ng-elemental/cli add theme, npx @ng-elemental/cli add icon, then npx @ng-elemental/cli add select

Usage

Project el-select-item children into el-select. The panel accepts any markup — groups, nested lists, or custom rows. A future tree can use the same selection token.
