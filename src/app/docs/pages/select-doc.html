Select

Combobox with an open panel slot. Use el-select-item for selectable rows (custom content allowed), and optionally ng-template elSelectValue for the closed trigger.

Pune Mumbai Delhi

Trigger uses native button with role="combobox", aria-expanded, and aria-controls on the listbox. Disabled uses the native disabled attribute.

Installation

Requires theme and icon.

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Project el-select-item children into el-select. Pair with el-label via ariaLabelledby or use ariaLabel when no visible label exists.

Multiple mode sets aria-multiselectable on the listbox. Arrow keys move active option focus while the panel is open.

Trigger value template (chips)

@if (selected.length === 0) { Select tags } @else { @for (item of selected; track item.value) { {{ item.label }} } } Angular Signals Accessibility

Custom trigger content must not replace the combobox accessible name. Keep ariaLabel or an external label via ariaLabelledby.
