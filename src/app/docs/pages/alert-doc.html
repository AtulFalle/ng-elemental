Alert

Inline status banner. The parent owns visibility — wrap in @if and handle dismissed. Requires the icon component.

Add to your project: npx @ng-elemental/cli add theme, npx @ng-elemental/cli add icon, then npx @ng-elemental/cli add alert

Installation

Usage

Do not hide the alert internally. Remove it from the template when dismissed.

Standards and checks

Alert follows live-region semantics for inline feedback.

  • Error and warning use role="alert"; info and success use role="status".
  • Dismiss button is keyboard operable with a visible focus indicator.
  • Semantic colors meet contrast on container backgrounds.
  • Parent owns visibility — no internal auto-dismiss timer.

References: APG Alert, A11Y Project Checklist, WCAG 2.2 (1.4.3, 4.1.3).
