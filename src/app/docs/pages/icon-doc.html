Standards and checks

Icons inherit naming from their parent control unless they stand alone.

  • Decorative default uses aria-hidden="true".
  • Meaningful standalone icons need [decorative]="false" and label.
  • Do not use icons as the only error or status cue — pair with text.
  • Icon color inherits from context for sufficient contrast.

References: A11Y Project Checklist, WCAG 2.2 (1.1.1, 1.4.11).
