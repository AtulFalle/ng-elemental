Empty State

Placeholder for an empty list, search, or page. Project an illustration, extra copy, and actions. Requires the icon component; examples also use button.

Add to your project: npx @ng-elemental/cli add theme, npx @ng-elemental/cli add icon, then npx @ng-elemental/cli add empty-state

Installation

Usage

Mark an illustration with elEmptyStateMedia and actions with elEmptyStateActions. Default content lands under the description. Empty slots collapse.

Standards and checks

Empty state announces status without trapping focus.

  • Host uses role="status" for the empty summary.
  • Heading and description provide the accessible message.
  • Primary next step is a native button in the actions slot.
  • Omitted slots collapse — no empty action rows.

References: A11Y Project Checklist, WCAG 2.2 (2.4.6, 4.1.3).
