Menubar

Horizontal application menu bar. The bar owns which top-level Menu is open. After one menu is open, hovering another trigger switches to it.

File New Open Save Edit Undo Redo Find Find in file Find in project View Command palette Appearance

Follows the APG menubar pattern: Arrow Down opens and focuses the first item, Arrow Up opens and focuses the last item, and Arrow Left/Right move between top-level menus while one is open.

Installation

Requires menu, icon, and button.

  1. Install the icon dependency if you use menu icons.

  3. Update the import paths to match your project setup.

Usage

Project el-menu children into the bar. Arrow Left/Right move between triggers. The menubar writes each menu’s open window; nested submenus keep their own open state.

Size adjusts bar density. Home and End jump to the first and last top-level menu triggers while a menu is open.

API Reference

Standards and checks

  • APG Menubar with role="menubar" and named via ariaLabel.
  • Arrow keys, Home, and End move between top-level triggers.
  • Hover switches menus once one menu is already open.

References: APG Menubar, A11Y Project Checklist.
