Pagination

Page window with prev/next, optional first/last, ellipsis, and an optional page-size select. Use it under Table or anywhere you page a list. It does not slice your data.

Uses a named navigation landmark. The current page is exposed with aria-current="page". Icon-only first, previous, next, and last controls include visually hidden text.

Usage

Bind page (1-based) and pass total. When the page changes, fetch or slice the visible window yourself. Set showPageSize to offer a rows-per-page select — changing it resets page to 1.

Many pages

Ellipsis placeholders are decorative and hidden from assistive technology. Numbered page buttons include an explicit page label.

Page size

The rows-per-page select is labelled for screen readers. Changing page size resets to page 1 so the current page never exceeds the new total.

Compact

Compact density keeps the same keyboard model and disabled states at the ends of the range.

Prev and next

Set showPages to false for a previous/next control without numbered pages.

Icon-only previous and next stay named with visually hidden text. Disabled at the ends of the range so the control count stays stable.
