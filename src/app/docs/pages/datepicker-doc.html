Date Picker

Select a date from a calendar, a time from an analog clock, or both. Type DD-MM-YYYY and HH:MM in number fields — they stay in sync with the calendar and clock. No native date/time inputs and no third-party date library.

Installation

Requires theme, icon, input, and segmented-button.

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Bind a Date | null with [(value)]. mode="date" shows a month grid with clickable month and year headers, plus DD-MM-YYYY fields at the bottom. mode="time" shows HH:MM, AM/PM, and a clock face. mode="datetime" switches between both in the same panel. The trigger always displays dd-MM-yyyy (plus time when needed).

Accessibility & keyboard

The trigger is a native button with an accessible name from visible text or ariaLabel. Press Enter, Space, ArrowDown, or ArrowUp to open the panel, and Escape to close it. In mode="datetime", the segmented tabs keep date and time controls in one dialog while preserving keyboard focus states.
