Navigation

Sidebar navigation for app shells and docs sidebars. Use el-tree for selectable hierarchies with checkboxes — navigation is for destinations, current page state, and expandable section links.

Favorites Mailboxes

Live examples omit href so the row is a button and stays on this page. Bind [(value)] to the current destination. In an app, pass href when the row should be a real link.

Usage

Soft

appearance="soft" fills the current row. Use it for app sidebars.

Active state uses a filled background and heavier weight, not color alone.

Rail

appearance="rail" is the no-fill style. The current item gets a left accent bar, like a docs table of contents.

Getting started Components

Active state uses a 2px primary bar and heavier weight, not color alone.

Size

Use size on el-nav to scale row padding and type.

Item content

Use string inputs for simple rows, or project elNavLeading, elNavLabel, elNavBadge, and elNavActions. Mail clients put the unread count on Inbox and a folder menu outside the row control.

Inbox

Actions sit outside the row control so a folder menu does not activate the item. Each action control needs its own accessible name.

Badges

Project el-badge with elNavBadge for unread counts or a NEW pill. Keep the mark non-interactive so it stays in the row name. Install badge if you use this slot.

Unread counts

New

Counts are visible text in the row, so screen readers include them in the name. Color is not the only cue: New also uses the word NEW. Prefer el-badge in this slot.

Nested

Nest el-nav-item elements for expandable sections. Bind [(expanded)] to control open parents. autoExpand reveals ancestors when value changes; you can still collapse those sections.

Getting started Components

Parent rows without href are disclosure buttons. With href and children, the label is a link and the chevron is a separate named disclosure control.

Expand mode

expandMode="single" keeps one sibling section open at each level, like GitHub settings (Account or Organization). Ancestors of the current item stay open.

Standards and checks

Navigation follows the native nav landmark and disclosure navigation patterns. Current page uses aria-current="page". Parent rows use aria-expanded and hide collapsed children with hidden and inert. A parent with both href and children follows disclosure navigation with top-level links: the link navigates, the chevron discloses.

  • Keyboard: Tab between links and buttons; Enter/Space toggles the disclosure control.
  • Focus-visible rings on interactive controls.
  • Chevron rotation honors prefers-reduced-motion.
