Standards and checks

Stack is a layout primitive with no widget role. Spacing and alignment follow flexbox semantics and survive 200% text zoom.

  • No role on the host — order comes from projected DOM.
  • Gap uses density tokens instead of ad-hoc margins.
  • Interactive controls inside the stack keep their native semantics.
  • Wrap is opt-in so long labels can reflow without overflow clipping.

References: A11Y Project Checklist, WCAG 2.2 (1.4.4, 1.4.10).
