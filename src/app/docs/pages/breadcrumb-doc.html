Breadcrumb

Navigation trail for the current page. The last item hides its separator automatically. Requires the icon component for the chevron.

Add to your project: npx @ng-elemental/cli add theme, npx @ng-elemental/cli add icon, then npx @ng-elemental/cli add breadcrumb

Usage

Use href for plain links. Omit it and project an a routerLink when you need the Angular router. Mark the last crumb with current.
