Home Components Breadcrumb

Renders a labelled nav with an ordered list. The current page uses aria-current="page". Separators are decorative.

Installation

Requires icon for the chevron.

  1. Install the icon dependency if you need the chevron.

  2. Copy and paste the following files into your project.

  3. Update the import paths to match your project setup.

Usage

Use href for plain links. Omit it and project an a routerLink when you need the Angular router. Mark the last crumb with current.
