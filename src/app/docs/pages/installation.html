Installation

Add NgElemental components to an existing Angular 22+ project using the CLI.

Before you begin

  • Theme (required for typography & tokens) — Geist fonts are bundled with the theme package. Import tokens.scss once; no extra font npm install.
  • Font Awesome (required for icons) — Only when using el-icon, button icons, or chip icons. Install @fortawesome/fontawesome-free and import fontawesome.scss in global styles.

1. Initialize the CLI

Run init from your Angular project root. This creates elemental.json and the default components directory.

Use --yes to skip prompts. Use add <name> --force to overwrite an existing component folder.

CLI reference

Command Description
npx @ng-elemental/cli init [--yes] Create config and components directory
npx @ng-elemental/cli add <name> [--force] Copy a component into your project

Available components: theme, icon, button, label, checkbox, slide-toggle, chip, segmented-button.
