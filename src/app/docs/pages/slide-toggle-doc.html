Slide Toggle

On/off switch with size variants, left/right inline text, and optional track or thumb icon slots.

Add to your project: npx @ng-elemental/cli add theme, then npx @ng-elemental/cli add slide-toggle. Custom on/off icons also need npx @ng-elemental/cli add icon.

Installation

Usage

Project inline text as content and bind on/off state with two-way binding.
