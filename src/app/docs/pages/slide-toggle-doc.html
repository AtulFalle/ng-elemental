Slide Toggle

On/off switch with size variants, left/right inline text, and optional track or thumb icon slots. Field label, error, and value accessors belong to el-form-error — this control is the switch primitive.

Add to your project: npx @ng-elemental/cli add theme, then npx @ng-elemental/cli add slide-toggle. Custom on/off icons also need npx @ng-elemental/cli add icon.

Usage

Project inline text as content and bind on/off state with two-way binding. Track icons use elSlideToggleTrackOnIcon / elSlideToggleTrackOffIcon. Thumb icons use elSlideToggleThumbOnIcon / elSlideToggleThumbOffIcon. The track gains horizontal padding when any of those slots have content.
