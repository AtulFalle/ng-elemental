Slide Toggle

On/off switch with size variants, left/right inline text, and optional track or thumb icon slots.

Notifications

Uses role="switch" with visible label text as the name. Space toggles while focused.

Installation

Custom on/off icons also need icon.

  1. Install the icon dependency if you need icons.

  2. Copy and paste the following files into your project.

  3. Update the import paths to match your project setup.

Usage

Project inline text as content and bind on/off state with two-way binding.

Track icons

Wi-Fi

Decorative track icons are marked aria-hidden so the inline label remains the accessible name.

States

On Disabled

Disabled uses native disabled on the switch input. Checked state is exposed to assistive technology.

Styling & tokens
