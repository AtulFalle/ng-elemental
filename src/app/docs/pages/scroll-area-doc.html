Scroll Area

Native overflow with a styled scrollbar. Set a height or width on the host so content can scroll. No JavaScript scrollbar.

Add to your project: npx @ng-elemental/cli add scroll-area

Installation

Usage

Give the host a fixed height or width and label the region with ariaLabel when the scrollable content is not self-describing.

Standards and checks

Scroll area is a labeled region with native overflow — not a custom scrollbar widget.

  • role="region" with aria-label when needed.
  • Keyboard users can scroll with arrow keys and Page Up/Down inside the region.
  • No zoom blocking — content reflows inside the fixed frame.
  • Thumb color meets 3:1 against the track for visibility.

References: APG Landmarks, A11Y Project Checklist, WCAG 2.2 (1.4.10, 1.4.11).
