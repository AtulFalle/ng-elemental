Label

An accessible form label with variant styles and optional required indicator.

Default Muted Error

Uses a native label element. Associate controls with htmlFor matching the control id.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Styling & tokens
