Input

Text field primitive with sizes, native types, prefix/suffix slots, and error or disabled styling. Pair with el-label and el-form-error for caption and message text. Mask is optional.

Email

Uses a native input with label association through inputId. Focus rings appear on keyboard navigation only via :focus-visible.

Usage

Bind the display string with [(value)]. Leave mask empty unless you need a pattern. Pair with el-label via inputId / htmlFor.

Types

Native input types preserve platform keyboards and validation where available. Prefer semantic types over generic text fields.

Decorative prefix and suffix content stays outside the native input so the control name comes from the label, not adornments.

Optional mask

Masking is optional formatting only. The bound value includes literal characters; do not rely on masks alone for validation.

States

Disabled uses the native attribute. Error sets aria-invalid and a distinct border — pair with el-form-error for the message text.
