Input

Text field primitive with sizes, native types, prefix/suffix slots, and error or disabled styling. Pair with el-label and el-form-error for caption and message text. Mask is optional.

Add to your project: npx @ng-elemental/cli add theme, then npx @ng-elemental/cli add input. Prefix or suffix icons also need npx @ng-elemental/cli add icon.

Installation

Usage

Bind the display string with [(value)]. Leave mask empty unless you need a pattern. Pair with el-label via inputId / htmlFor.

Standards and checks

  • Native text input semantics with label association via inputId.
  • Visible :focus-visible ring on keyboard focus only.
  • aria-invalid and aria-describedby for errors.
