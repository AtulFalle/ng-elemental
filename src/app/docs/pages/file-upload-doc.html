File Upload

Dropbox-style dropzone with browse control, validation messages, and an auto-rendered Attachment list. Selection UI only — your app owns HTTP upload and progress.

Add to your project: npx @ng-elemental/cli add file-upload (requires attachment, button, icon, form-error)

Preview

Drag and drop, or browse to select a file

Installation

Usage

Bind files with [(files)] . Project hint text as content. Invalid files surface through el-form-error .

Examples

Multiple with constraints

PNG, JPG, or PDF — up to 5 files, 5 MB each

Upload progress

File Upload only selects files. Wire Progress with Attachment when your app owns HTTP upload — see the Storybook With Progress story under File Upload.

Styling & tokens

Colors come from generic theme tokens. Open tokens.scss and edit the BRAND block, or override --el-color-primary on a wrapper. See Theming for the full token list.
