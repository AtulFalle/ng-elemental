File Upload

Dropbox-style dropzone with browse control, validation messages, and an auto-rendered Attachment list. Selection UI only — your app owns HTTP upload and progress.

Drag and drop, or browse to select a file

The dropzone exposes an accessible name via dropTitle. The browse button associates with the hidden file input through aria-controls and aria-labelledby.

Installation

Requires attachment, button, icon, and form-error.

  1. Install the icon dependency.

  2. Copy and paste the following files into your project.

  3. Update the import paths to match your project setup.

Usage

Bind files with [(files)]. Project hint text as content. Invalid files surface through el-form-error.

Multiple with constraints

PNG, JPG, or PDF — up to 5 files, 5 MB each

Validation errors use role="alert" via el-form-error. Drag-and-drop and keyboard activation share the same file picker entry point.

File Upload only selects files. Wire Progress with Attachment when your app owns HTTP upload — see the Storybook With Progress story.
