Stepper

Tab-like step list that shows one ng-template at a time. Click any enabled step, or call next() / previous() from buttons you compose yourself.

Create the account used to sign in.

Choose a plan.

Review and finish.

Step buttons use aria-current="step" on the active step. Inactive panel content is not mounted until its step is selected.

Installation

Requires icon.

  1. Install the icon dependency.

  2. Copy and paste the following files into your project.

  3. Update the import paths to match your project setup.

Usage

Import the stepper, step, and content directive. Put panel markup in <ng-template elStepContent> so inactive steps are not created. Optional elStepLabel templates replace the text label.

Standards and checks

  • Step list uses tab-like buttons with aria-current="step" on the active step.
  • Inactive step panels are not mounted until selected.
  • Linear mode disables steps more than one ahead with aria-disabled.
