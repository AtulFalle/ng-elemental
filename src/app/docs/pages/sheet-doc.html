Sheet

Edge panel with header, scrolling content, and footer slots. Open it in the template with [(open)] or from ElSheetService.open() with a custom component and injected data.

Open sheet
Header and footer stay put. Long content scrolls inside the panel.
Cancel Apply

Sheets trap focus while open, restore it on dismiss, and expose a named dialog role. Escape and backdrop clicks dismiss unless disabled.

Installation

Requires icon and button.

  1. Install icon and button for the close control.

  2. Copy and paste the following files into your project.

  3. Update the import paths to match your project setup.

Usage

Mark projected nodes with elSheetHeader, elSheetContent, or elSheetFooter. Empty slots collapse. Use elSheetClose on a button to dismiss.

Left side

Open from the left
A left sheet uses width sizes instead of height.
Close

Side controls which viewport edge the panel attaches to. Size maps to width for left/right sheets and max-height for top/bottom sheets.
