Aspect Ratio

Locks a box to a CSS aspect-ratio. The default slot fills the box — size media with width/height: 100% and object-fit.

16 / 9

Video and cover art use 16:9 so layout does not shift while media loads. Provide meaningful alt text on images inside the frame.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Wrap media or placeholders that must keep a fixed proportion while the width changes.

Square

1 / 1

Square frames suit thumbnails and avatars. The ratio box reserves space so surrounding content does not jump when assets arrive.

API Reference

Standards and checks

Aspect ratio is a sizing wrapper only. Accessibility comes from projected content.

  • No widget role on the host.
  • Images need appropriate alt — empty alt only when decorative.
  • Reserved space reduces cumulative layout shift during load.

References: A11Y Project Checklist, WCAG 2.2 (1.1.1, 1.4.10).
