MCP server

Give coding agents a live catalog of NgElemental widgets: search, inspect usage, and copy source into the project through the CLI.

What it is for

NgElemental MCP is for El* components, directives, and services. Keep Angular CLI MCP for workspace, docs, and builds. Agents should call get_guidelines first, then search and add.

Tools

  • get_guidelines — design rules and how to wire a widget into a page
  • search_components — find widgets by name or intent (dropdown, modal)
  • list_components — catalog dump, optional kind filter
  • get_component — usage, dependencies, import path, wire-in checklist
  • add_components — copy source via @ng-elemental/cli
  • init_project — create elemental.json and theme tokens

Resource ng-elemental://guidelines is the same guide as get_guidelines.
