Tooltip

Attribute directive that shows a short inverted label on hover and focus. An arrow on the bubble points at the host. The bubble is portaled to document.body so it is not clipped by overflow.

Save

Tooltips supplement the host name on hover and focus. Escape dismisses an open tip without moving focus away from the control.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Put elTooltip on any host. Disabled native buttons do not fire mouse events — wrap them if the tip must still show.

Positions

Top Bottom Start End

Placement prefers top, bottom, start, or end relative to the host. Start and end follow text direction so tips stay readable in RTL layouts.

Disabled

Disabled tip

Use elTooltipDisabled when a tip should not appear even though the host remains focusable or hoverable.

API Reference

Standards and checks

Tooltips expose supplementary text through aria-describedby while the host keeps its primary accessible name.

  • Opens on hover and keyboard focus; closes on blur, Escape, and pointer leave.
  • Empty or disabled tips never mount a bubble.
  • Portaled bubble avoids clipping from overflow ancestors.

References: APG Tooltip, A11Y Project Checklist.
