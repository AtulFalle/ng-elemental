Tooltip

Attribute directive that shows a short inverted label on hover and focus. An arrow on the bubble points at the host. The bubble is portaled to document.body so it is not clipped by overflow.

Add to your project: npx @ng-elemental/cli add tooltip

Save

Installation

Usage

Put elTooltip on any host. Disabled native buttons do not fire mouse events — wrap them if the tip must still show.
