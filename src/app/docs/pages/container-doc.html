Container

Centered max-width wrapper. Project any content — the container is not interactive.

Constrained to 40rem

Max-width keeps line length readable for body copy. Horizontal padding prevents content from touching viewport edges on small screens.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Sizes are hardcoded max-widths. Use full to drop the cap.

Full bleed

Edge-to-edge content

Full width is for hero bands and media rails. Disable padding only when the child already handles inset spacing.

API Reference

Standards and checks

Container centers content and caps width. It is not a landmark or interactive region.

  • No role on the host — use landmarks on inner sections when needed.
  • Readable line length supports WCAG reflow at 200% zoom.
  • Padding uses density tokens for consistent gutters.

References: A11Y Project Checklist, WCAG 2.2 (1.4.8, 1.4.10).
