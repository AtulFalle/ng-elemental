Avatar

Circular user or entity mark. Content priority: src → initials → icon (default user). Image load errors fall through to the next option.

Every avatar needs an accessible name via alt. Images use native alt; initials and icon fallbacks use aria-label.

Usage

Pass a truncated initials string yourself. Requires npx @ng-elemental/cli add icon for the icon fallback.

Sizes

Sizes scale the mark without changing naming. Failed image loads fall back to initials or icon automatically.

Custom icon

Custom icons still require alt text. The icon is decorative inside the named avatar shell.

API Reference

Standards and checks

Avatar is presentational identity — not a button unless wrapped by one.

  • Images expose alt; fallbacks use role="img" and aria-label.
  • Broken images fall through to initials or icon without losing the name.
  • Initials contrast meets WCAG against the fallback fill.
  • Do not make the avatar itself clickable — wrap with a link or button when needed.

References: A11Y Project Checklist, WCAG 2.2 (1.1.1, 1.4.3).
