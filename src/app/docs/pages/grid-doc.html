Grid

CSS grid wrapper. Use a column count, or minItemWidth for responsive auto-fit. Children are projected as-is.

@for (item of columnItems; track item) {
{{ item }}
}

Fixed columns suit dashboards with predictable tile counts. Reading order follows DOM order left-to-right, top-to-bottom.

Usage

Prefer minItemWidth when the grid should reflow without a breakpoint map.

Auto-fit

@for (item of autoFitItems; track item) {

Auto-fit reflows tiles without JavaScript breakpoints. Tiles stay readable when users zoom or narrow the viewport.

API Reference

Standards and checks

Grid is presentational layout. It does not define landmarks or interactive behavior.

  • No widget role — structure comes from child content.
  • DOM order defines screen-reader sequence.
  • Gap tokens replace brittle margin hacks between cells.
  • Cards and buttons inside cells keep their own semantics.

References: A11Y Project Checklist, WCAG 2.2 (1.4.10).
