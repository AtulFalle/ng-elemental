Grid

CSS grid wrapper. Use a column count, or minItemWidth for responsive auto-fit. Children are projected as-is.

Add to your project: npx @ng-elemental/cli add grid

Preview

@for (item of ['One', 'Two', 'Three', 'Four', 'Five', 'Six']; track item) {
{{ item }}
}

Installation

Usage

Prefer minItemWidth when the grid should reflow without a breakpoint map.
