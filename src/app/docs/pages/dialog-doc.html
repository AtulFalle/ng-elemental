Dialog

Modal overlay on a native <dialog> element. Open it in the template with [(open)] or from ElDialogService.open().

Native <dialog> with showModal() provides the top layer, inert background, focus trap, and Escape. The visible title is an h2 that names the dialog.

Usage

Mark projected nodes with elDialogHeader, elDialogContent, or elDialogFooter. Empty slots collapse. Use elDialogClose on a button to dismiss.

Standards and checks

Dialog uses the native modal <dialog> element and the APG Dialog (Modal) pattern: focus in, trap, Escape, restore, and a name.

  • Native showModal() for top layer, inert background, and Tab trap.
  • Visible title is an h2 referenced with aria-labelledby (or ariaLabel).
  • Escape dismisses unless closeOnEscape is false (cancel is prevented).
  • Focus returns to the trigger on close.
  • Close control is a named <button type="button">.
  • Content scrolls inside a viewport-capped shell and is tabindex="0" so the region can be scrolled from the keyboard (1.4.4 / 1.4.10).

References: APG Dialog (Modal), HTML dialog element, A11Y Project Checklist, WCAG 2.2.
