Dialog

Modal overlay with header, scrolling content, and footer slots. Open it in the template with [(open)] or from ElDialogService.open() with a custom component and injected data.

Add to your project: npx @ng-elemental/cli add dialog (requires icon; examples also need button)

Installation

Usage

Mark projected nodes with elDialogHeader, elDialogContent, or elDialogFooter. Empty slots collapse. Use elDialogClose on a button to dismiss.

Examples

Scrolling content

The shell is capped to the viewport. Only the content region scrolls.

Open with a service

No extra host in the app shell. open() mounts the dialog on document.body and injects EL_DIALOG_DATA plus ElDialogRef into the custom component. The component fills the content slot; chrome comes from the options.
