Radio

Material Design 3 radio buttons with label placement and vertical or horizontal group layouts.

Email Phone Mail

Group exposes role="radiogroup" with ariaLabel. Each option uses a native radio input.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Wrap radios in el-radio-group and bind the selected value with two-way binding:

Horizontal group

Small Medium Large

Arrow keys move selection within the group per APG radio group keyboard guidance.

States

Disabled group Available Unavailable

Disabled groups and options use native disabled so assistive technology exposes the inactive state.
