Introduction

NgElemental provides copy-paste Angular UI components. Run the CLI and component source files land in your project — you own and customize the code.

What makes it different

NgElemental is not a traditional npm UI library. Components are added as source (TypeScript, HTML, SCSS) so you can adapt styling, behavior, and structure without fighting a black-box dependency.

Requirements

  • Angular 22 or later
  • Node.js 24 or later (for the CLI)
  • Theme — add with npx @ng-elemental/cli add theme. Includes design tokens and bundled Geist fonts with system-ui fallbacks. No separate font npm package is required.
  • Font Awesome 6 (optional) — required only when using el-icon or icon props on buttons and chips. Install @fortawesome/fontawesome-free and import fontawesome.scss once in global styles.

Components use encapsulated SCSS with BEM-style class names and design tokens as CSS custom properties. Tailwind is not required.

See Installation for step-by-step setup of theme, fonts, and icons.

Quick start

From your Angular project:

init creates elemental.json and a components directory (default: src/app/ui).

add copies the selected component into that directory. See Installation for full setup including typography.

Available components

  • Icon — Font Awesome icons by name
  • Button — primary actions and form controls
  • Label — accessible form labels
  • Form Error — presentational validation message
  • Input — text field with types, prefix/suffix, and optional mask
  • Checkbox — Material Design 3 checkbox with label text
  • Slide Toggle — on/off switch with size and label position
  • Select — combobox with custom items, groups, and multi-select
  • Date Picker — calendar and analog clock with DD-MM-YYYY / HH:MM fields
  • Date Range Picker — start–end calendar series with DD-MM-YYYY fields
  • Chip — assist, filter, and suggestion chips with start/end icons
  • Progress — line and circle progress (determinate + indeterminate)
  • Segmented Button — single-choice view or option switcher
