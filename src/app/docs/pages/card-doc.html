Card

Presentational container with named slots for media, header, content, and footer. Put whatever you need in each slot — including Avatar and buttons.

Add to your project: npx @ng-elemental/cli add card

Usage

Mark projected nodes with elCardMedia, elCardHeader, elCardContent, or elCardFooter. The card itself is not interactive.
