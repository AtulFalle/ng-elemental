Usage

Mark projected nodes with elCardMedia, elCardHeader, elCardContent, or elCardFooter. Nest elCardTitle and elCardDescription in the header when you need title typography. Size media inside el-aspect-ratio with width/height: 100% and object-fit: cover. Omit unused slots so they collapse.

Standards and checks

Card is a layout primitive. It does not take a widget role. Actions and links belong in the slots, using native controls.

  • No role on the host — grouping comes from visible structure.
  • Whole-card click is avoided so footer buttons are not nested controls.
  • elCardTitle / elCardDescription give consistent header typography without inline styles.
  • Compose media with el-aspect-ratio; size images with object-fit: cover so the frame crops cleanly.
  • Omitted slots collapse; footer padding stays even when the body is empty.
  • Default and compact footers end-align actions; compact does not wrap actions under the name.
  • Outlined border uses --el-color-outline for 3:1 against surface.
  • Long text wraps (default) or ellipsizes (compact) without overlapping actions.
  • Grid cells stretch so cards align across unequal copy.

References: APG Landmarks, A11Y Project Checklist, WCAG 2.2 (1.1.1, 1.4.4, 1.4.10, 1.4.11).
