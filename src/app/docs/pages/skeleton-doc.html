Skeleton

Presentational loading placeholders for text, avatars, and blocks, or a directive that covers any host with a skeleton matching that element. Mark the surrounding region with aria-busy — el-skeleton itself is hidden from assistive tech.

Add to your project: npx @ng-elemental/cli add skeleton

Preview

Installation

Usage

Place el-skeleton where content will land, or put [elSkeleton] on the control itself. Set aria-busy="true" on the loading region.
