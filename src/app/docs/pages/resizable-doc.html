Resizable

Split panes with a draggable, keyboard-accessible handle. The group owns sizes; panels expose min/max; the handle emits pointer and key deltas.

Sidebar
Main

The handle is a focusable separator with role="separator" and aria-orientation. Arrow keys resize; Home and End jump to min/max.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Place a handle between two panels. Arrow keys nudge 2%; Home and End jump to that split’s min and max. Sizes stay in percents — they are not persisted.

Vertical

Top
Bottom

Vertical orientation swaps the resize axis. Up/Down arrows nudge the split instead of Left/Right.

Min / max

The first pane cannot shrink below 25% or grow above 60%.

Rest

Min and max clamp keyboard and pointer resizing so panes never collapse below a usable size.

Standards and checks

  • Arrow keys nudge 2%; Home and End jump to min and max.
  • Pointer drag and keyboard resize share the same min/max constraints.
