Slider

Horizontal value picker with a single thumb or a dual-thumb range. Supports step snapping, optional tick marks, and value labels.

Add to your project: npx @ng-elemental/cli add slider

Installation

Usage

Bind [(value)] for a single thumb. Set range and bind [(start)] / [(end)] for a range. Customize thumb names with ariaLabel inputs.
