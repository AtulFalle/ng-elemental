Slider

Horizontal value picker with a single thumb or a dual-thumb range. Supports step snapping, optional tick marks, and value labels.

Thumbs use role="slider" with localizable aria-label, value min/max/now, and aria-orientation.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Bind [(value)] for a single thumb. Set range and bind [(start)] / [(end)] for a range. Customize thumb names with ariaLabel inputs.

Range

Range mode exposes two independently named thumbs. Arrow keys, Home, End, and Page Up/Down adjust values per APG slider guidance.

Disabled / error

Disabled thumbs use the native disabled attribute. Error styling adds a non-color-only border cue on the thumb.

Styling & tokens
