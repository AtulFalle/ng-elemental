Infinite Scroll

Attribute directive that emits loadMore when the user reaches the end of a scroll container. Your parent owns pages, loading, and completion — this demo uses List for the rows.

The sentinel fires loadMore when near the scroll bottom. Bind [disabled] while fetching and show a progress indicator so users know more content is loading.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Put elInfiniteScroll on a wrapper with overflow: auto and a max height (default root="host"). Bind [disabled] to your in-flight flag and [complete] when there is no next page. Append items in (loadMore).

Standards and checks

  • Loading state is visible — progress indicator while fetching the next page.
  • [complete] stops further requests and shows an end-of-list message.
  • Scroll container has a max height and overflow: auto for keyboard scroll.
