Standards and checks

Toast notifications are transient status messages — not modal dialogs.

  • role="status" on each toast; toaster manages the live region.
  • Dismiss control is a named button operable by keyboard.
  • Auto-dismiss does not steal focus from the page.
  • Semantic colors pair icon and text — not color alone.

References: APG Alert (transient), A11Y Project Checklist, WCAG 2.2 (2.2.1, 4.1.3).
