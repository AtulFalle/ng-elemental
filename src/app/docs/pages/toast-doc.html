Toast

Overlay notifications. Place el-toaster once in the app shell, then call ElToastService.show(). Requires the icon component.

Add to your project: npx @ng-elemental/cli add theme, npx @ng-elemental/cli add icon, then npx @ng-elemental/cli add toast

Usage

The service owns the toast list and timers. el-toast is presentational only. For a single action bar with auto-dismiss, use Snackbar.
