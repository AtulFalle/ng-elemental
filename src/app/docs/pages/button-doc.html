Usage

Size

Use the size prop to change the size of the button. Icons stay sm through md and step up to md on lg.

Medium
Large

Sizes keep spacing and readability consistent while preserving minimum touch target expectations for interactive controls.

Primary

Button

Primary is the highest-emphasis action. Prefer one primary action per view so hierarchy stays clear.

Secondary

Secondary

Secondary is the default bordered look for supporting actions beside a primary control.

Outline

Outline

Outline keeps a visible border on a transparent fill. Use it when the action needs a control shape without competing with primary.

Ghost

Ghost

Ghost keeps low visual weight for tertiary actions without looking disabled.

Destructive

Delete

Destructive is for irreversible actions. Pair the error color with a clear label such as Delete so color is not the only cue.

Icon

Icon-only controls require an accessible name via ariaLabel. The icon variant keeps a consistent square target. Glyphs stay sm through md buttons and use md on lg.

With Icon

Use iconStart or iconEnd for icon spacing before or after the label.

New Branch Fork

Start and end icons keep label and icon spacing predictable without custom CSS.

Rounded

Override border-radius on a wrapper to make the button fully rounded.

Get Started

Rounding is composition via CSS, not a separate variant, so token-based corners stay the default.

Loading

Set loading to show a spinner and mark the control busy. Use loadingLabel for the announced text.

Generating Downloading

Loading marks the action busy and prevents repeated activation while work is in progress.

Segmented Button

For exclusive choices styled as a connected group, use Segmented Button. It is a radiogroup, not a cluster of independent actions.

List Grid Board

Segmented Button uses role="radiogroup" with arrow-key selection. Prefer a future Button Group for independent actions.

As a link

el-button always renders a native <button>. To style a link like a button, put button classes on a plain <a> (or wait for an as-link helper). Do not force role="button" onto anchors.

RTL

API Reference

The ElButton component wraps a native <button> with variants, sizes, icons, and loading state.

Standards and checks

Button behavior prioritizes native semantics and WCAG 2.2 AA outcomes for keyboard, focus, motion, contrast, and touch accessibility.

  • APG Button pattern with native Enter/Space activation.
  • Visible :focus-visible indication for keyboard navigation.
  • Distinct default, hover, active, disabled, and loading states.
  • Outline and destructive variants with labels so color is not the only cue.
  • Accessible naming requirement for icon-only actions.
  • Reduced-motion support for non-essential animation.

References: APG Button, APG Keyboard Interface, A11Y Project Checklist, WCAG 2.2.
