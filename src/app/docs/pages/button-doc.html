Button

A styled button component with variant and size options for actions and form controls.

Add to your project: npx @ng-elemental/cli add icon (for icons), npx @ng-elemental/cli add button

Standards and checks

Button behavior prioritizes native semantics and WCAG 2.2 AA outcomes for keyboard, focus, motion, contrast, and touch accessibility.

  • APG Button pattern with native Enter/Space activation.
  • Visible :focus-visible indication for keyboard navigation.
  • Distinct default, hover, active, disabled, and loading states.
  • Primary label contrast meets WCAG 2.2 AAA 7:1 against the default brand fill.
  • Accessible naming requirement for icon-only actions.
  • Reduced-motion support for non-essential animation.

References: APG Button, APG Keyboard Interface, A11Y Project Checklist, WCAG 2.2.
