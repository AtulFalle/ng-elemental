Progress

Line and circle progress indicators with determinate values or an indeterminate animation. One CLI package installs both el-progress and el-progress-circle.

Determinate bars expose aria-valuenow, aria-valuemin, and aria-valuemax. Indeterminate mode omits a value and uses motion that honors prefers-reduced-motion.

Installation

  1. Copy and paste the following files into your project.

  2. Update the import paths to match your project setup.

Usage

Pass value and optional max (default 100). Use indeterminate when progress is unknown. Both components share the same inputs.

Line sizes

Visible percent labels supplement the bar for users who need numeric feedback. Track fill color is not the only cue when showValue is on.

Indeterminate

Use indeterminate progress only when duration is unknown. Pair with status text when the operation name is not obvious from context.

API Reference

Shared by el-progress and el-progress-circle.

Standards and checks

Progress uses the native progressbar role.

  • Determinate values map to aria-valuenow / aria-valuemax.
  • Indeterminate bars omit aria-valuenow.
  • Animation respects prefers-reduced-motion.
  • Fill and track meet 3:1 non-text contrast where applicable.

References: APG Progressbar, A11Y Project Checklist, WCAG 2.2 (1.4.11, 2.2.2).
