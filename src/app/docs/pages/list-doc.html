List

Vertical collection of rows with optional leading media, title, description, and trailing meta. Pair with Infinite Scroll for paginated feeds. Pass virtual with [items] and elListItemDef for long lists.

Uses a semantic list with named slots for title, description, and trailing meta. Pass ariaLabel when the list purpose is not obvious from context.

Usage

Project row content into elListLeading, elListTitle, elListDescription, and elListTrailing. Plain text without slots works too.

Plain text rows

Plain text rows work without slots. Disabled rows expose aria-disabled and are skipped by keyboard activation.

Interactive selection

@for (person of people; track person.id) { {{ person.name }} {{ person.role }} }

The parent owns which row is selected. Items emit activated on click, Enter, or Space. Selected rows expose aria-selected="true".

Virtual

{{ person.name }} {{ person.role }}

Set a max-height on el-list. Rows use a fixed itemHeight. Keyboard focus still moves through the rendered window.

Trailing actions

report.pdf 2.4 MB cover.png 840 KB

Trailing actions in elListTrailing do not activate the row. Each icon button needs a descriptive aria-label.

Sizes

@for (size of sizes; track size) { {{ size }} density Title, description, trailing meta 2 }

Size adjusts padding and type scale. Interactive and selection behavior is unchanged across densities.

Standards and checks

  • Semantic list structure with labelled title and description slots.
  • Interactive rows are focusable and activate on Enter or Space.
  • Selected rows expose aria-selected; disabled rows use aria-disabled.
