List

Vertical collection of rows with optional leading media, title, description, and trailing meta. Pair with Infinite Scroll for paginated feeds. Pass virtual with [items] and elListItemDef for long lists.

Add to your project: npx @ng-elemental/cli add list

Installation

Usage

Project row content into elListLeading, elListTitle, elListDescription, and elListTrailing. Plain text without slots works too.

Standards and checks

  • Semantic list structure with labelled title and description slots.
  • Interactive rows are focusable and activate on Enter or Space.
  • Selected rows expose aria-selected; disabled rows use aria-disabled.

References: APG Listbox (selection), A11Y Project Checklist.
