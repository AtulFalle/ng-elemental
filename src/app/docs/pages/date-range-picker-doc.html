Date Range Picker

Two months side by side, without time. Click a start day then an end day, or type From / To as DD-MM-YYYY. Use the arrows or the month and year labels to move either calendar. In-between days highlight as a series.

Add to your project: npx @ng-elemental/cli add theme, npx @ng-elemental/cli add icon, npx @ng-elemental/cli add input, npx @ng-elemental/cli add segmented-button, then npx @ng-elemental/cli add datepicker

Usage

Bind a start / end object with [(value)]. Two months are shown at once. Click the month or year in either header to jump, or use the previous / next arrows. The first click (or complete From fields) sets start; the second sets end and closes the panel. If the second day is before the first, the ends swap. Hover previews the range after start is chosen.

Accessibility & keyboard

The trigger is a native button with a clear accessible name. Press Enter, Space, ArrowDown, or ArrowUp to open, then Escape to close. Previous and next month controls are labeled buttons, and both calendars expose a single continuous range selection with hover preview feedback.
