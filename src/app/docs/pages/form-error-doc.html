Form Error

Presentational validation message. Compose it with el-label and any control yourself — no wrapper coupling. Validation logic stays in your app; this component only displays the message.

Add to your project: npx @ng-elemental/cli add form-error

Preview

Usage

Pair label, control [error], and el-form-error. Wire aria-describedby when you want the message announced with the control.
