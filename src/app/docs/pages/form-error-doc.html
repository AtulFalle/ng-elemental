Form Error

Presentational validation message. Compose it with el-label and any control yourself — no wrapper coupling.

Add to your project: npx @ng-elemental/cli add form-error

Installation

Usage

Pair label, control [error], and el-form-error. Wire ariaDescribedby on the control when you want the message announced with the field.
