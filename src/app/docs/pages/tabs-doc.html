Tabs

Switch between related views in one panel. Tab content is an ng-template, so you can pass any HTML. When tabs overflow, chevrons scroll the strip so remaining tabs can be selected.

Project overview, status, and recent activity.

Invoices, payment methods, and billing contacts.

Members, roles, and pending invitations.

Tabs follow the APG tabs pattern: roving tabindex on tab buttons, arrow-key navigation, and aria-selected on the active tab.

Usage

Import the tabs, tab, and content directive. Put panel markup in <ng-template elTabContent> so inactive panels are not created. Optional elTabLabel templates let the tab header contain any HTML (icons, badges, and so on).

Standards and checks
