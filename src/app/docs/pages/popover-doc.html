Usage

el-popover is a controller with no chrome. Mark the trigger with elPopoverTrigger and project content into el-popover-panel. Optional elPopoverTitle is a slot, not a show/hide flag. elPopoverClose dismisses the panel.

API Reference

Standards and checks

  • Trigger exposes aria-expanded; panel is labelled via title or ariaLabel.
  • Modal mode traps focus and dismisses on Escape or backdrop click.
  • Hover trigger is for rich content — not a replacement for Tooltip.
