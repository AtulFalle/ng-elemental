Menu

Command menu with a floating panel, nested submenus, and an optional context-menu trigger. Use Menubar for a persistent application bar, and Popover for arbitrary content — not commands. Short hover text stays on Tooltip.

Add to your project: npx @ng-elemental/cli add menu (requires icon and usually button)

Installation

Usage

el-menu is a controller with no chrome. Project a trigger with elMenuTrigger and items into el-menu-panel. Nest another el-menu for a submenu. Escape, outside click, and Tab close the tree. Checkbox and radio items emit selected; the parent owns checked.

Standards and checks

  • APG Menu with role="menu", menuitem, and nested submenus.
  • Arrow keys, Home, End, and typeahead move between items.
  • Escape, outside click, and Tab close the menu tree.
