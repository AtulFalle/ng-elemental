Menu

Command menu with a floating panel, nested submenus, and an optional context-menu trigger. Use Menubar for a persistent application bar, and Popover for arbitrary content — not commands. Short hover text stays on Tooltip.

Actions Cut Copy Share Email Copy link Delete

Follows the APG menu pattern with role="menu" and menuitem. Arrow keys move between items; Escape closes the tree.

Installation

Requires icon and usually button.

  1. Install the icon dependency if you use menu icons.

  2. Copy and paste the following files into your project.

  3. Update the import paths to match your project setup.

Usage

el-menu is a controller with no chrome. Project a trigger with elMenuTrigger and items into el-menu-panel. Nest another el-menu for a submenu. Escape, outside click, and Tab close the tree. Checkbox and radio items emit selected; the parent owns checked.

Checkbox and radio

Checkbox and radio items use menuitemcheckbox and menuitemradio roles. Checked state is parent-owned; items emit selected on activate.
