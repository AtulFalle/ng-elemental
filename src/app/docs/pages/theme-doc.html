Theming

NgElemental components read design tokens as CSS custom properties. Override tokens globally, per section, or at runtime — no need to edit component SCSS.

Add theme files to your project: npx @ng-elemental/cli add theme

Setup

The theme package copies tokens.scss and optional ElThemeService into your components directory. Import tokens once in your global styles so every component receives default values:

Components reference tokens with var(--el-…). As long as tokens are loaded, styling stays consistent and overridable.

Dark mode

Built-in dark palette values live under [data-el-theme='dark'] in tokens.scss. Enable dark mode by:

  • Calling ElThemeService.setMode('dark')
  • Passing mode: 'dark' to provideElTheme()
  • Setting data-el-theme="dark" on <html>
