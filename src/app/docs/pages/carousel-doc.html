Carousel

Slide track with previous/next controls and dots. Optional loop, autoplay, and a peek of adjacent slides. This is not the Slider range input.

One
Two
Three

Uses a named region with prev/next buttons and dot indicators. The active slide is exposed with aria-hidden on inactive panels. Pass ariaLabel to name the carousel.

Usage

The parent owns index. Prev/next and dots live on el-carousel. Each el-carousel-slide is only a panel — do not put chrome inside the slide.

Standards and checks

  • Named carousel region with labelled prev/next and dot controls.
  • Inactive slides hidden with aria-hidden.
  • Autoplay pauses on hover, focus, drag, and prefers-reduced-motion.
