Snackbar

Transient bar with a built-in action or projected controls. Open it in the template with [(open)] or from ElSnackbarService.open(). Stacked corner notifications stay on Toast.

Add to your project: npx @ng-elemental/cli add theme, npx @ng-elemental/cli add icon, then npx @ng-elemental/cli add snackbar (custom actions also need button)

Usage

The parent owns open in the template. The built-in action label dismisses after click. Project any number of controls with elSnackbarActions — those do not auto-dismiss, so keep duration at 0 for a selection bar. The service mounts one bar on document.body and replaces it if you open again.
