Snackbar

Transient bar with a built-in action or projected controls. Open it in the template with [(open)] or from ElSnackbarService.open(). Stacked corner notifications stay on Toast.

Show snackbar

Built-in actions are native buttons with visible labels. Error bars use role="alert" and assertive live regions; others stay polite.

Usage

The parent owns open in the template. The built-in action label dismisses after click. Project any number of controls with elSnackbarActions — those do not auto-dismiss, so keep duration at 0 for a selection bar. The service mounts one bar on document.body and replaces it if you open again.

Standards and checks

Snackbar is a transient bar — not a dialog — with optional undo.

  • Error uses role="alert" and aria-live="assertive".
  • Other tones use role="status" and polite live regions.
  • Action and dismiss controls are keyboard reachable with visible focus.
  • Auto-dismiss timer clears when duration is zero.

References: APG Alert, A11Y Project Checklist, WCAG 2.2 (2.2.1, 4.1.3).
