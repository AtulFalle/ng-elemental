Checkbox

Material Design 3 checkbox with label text, left/right label placement, and indeterminate support.

Accept terms and conditions

Uses a native checkbox with visible label text as the accessible name. Focus ring appears on keyboard focus via :focus-visible.

Installation

Requires icon.

  1. Install the icon dependency if you need icons.

  2. Copy and paste the following files into your project.

  3. Update the import paths to match your project setup.

Usage

Project label text as content and bind checked state with two-way binding:

Checkbox list

Notifications Marketing emails Select all

Indeterminate state exposes aria-checked="mixed" for parent/select-all patterns.

States

Checked Disabled Error

Disabled uses the native attribute. Error adds a border cue beyond color alone.

Styling & tokens
