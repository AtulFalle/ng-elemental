Separator

Horizontal or vertical rule. Distinct from the menu-only el-menu-separator.

Add to your project: npx @ng-elemental/cli add separator

Installation

Usage

Leave decorative on for visual dividers. Set [decorative]="false" when the split is meaningful to AT.

Standards and checks

Separator follows the APG separator pattern when not decorative.

  • Decorative default uses aria-hidden="true".
  • Semantic splits expose role="separator" and aria-orientation.
  • Color alone is not the only cue — adjacent labels carry meaning.
  • Border color meets 3:1 against the surface.

References: APG Separator, A11Y Project Checklist, WCAG 2.2 (1.4.11).
