Tree

Hierarchical files-and-folders list. Project nested el-tree-item rows, or pass [nodes] for checkboxes, virtualization, lazy children, and load more.

Follows the APG tree pattern with role="tree" and aria-expanded on parent rows. Arrow keys move between items; Left collapses, Right expands.

Usage

The parent owns expanded and checked. Project leading media with elTreeLeading and row actions with elTreeActions. Nested el-tree-item children form the hierarchy.

Cascade checkboxes

Checking a folder checks descendants. A mixed folder shows indeterminate via aria-checked="mixed". The checked model stores subtree roots only.

Actions

Trailing actions sit in elTreeActions and do not activate the row. Each action button needs its own accessible name.

Virtual

{{ node.label }}

Virtual mode flattens expanded rows and requires [nodes] plus a max-height. Keyboard focus still moves through the visible window.

Lazy children and load more

{{ node.label }}

Expanding a node with hasChildren and no children emits loadChildren. Loading rows expose aria-busy while children fetch.

Root infinite scroll

Root-level paging is not built in. Compose Infinite Scroll around the tree.

Wrap the tree in a scroll container with elInfiniteScroll. Bind [disabled] while loading and [complete] when there are no more root nodes.

Sizes

Size adjusts row padding and type scale. Keyboard and ARIA behavior is unchanged across densities.
