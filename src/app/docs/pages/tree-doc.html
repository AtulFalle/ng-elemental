Usage

The parent owns expanded and checked. Project leading media with elTreeLeading, always-visible badges or status with elTreeMeta, and row actions with elTreeActions. Each slot accepts as many matching nodes as you pass. Nested el-tree-item children form the hierarchy. Rows are flush by default — set appearance="outlined" only when the tree itself should be a boxed picker.

File actions

Put a Menu in elTreeActions. Clicks on the trailing control do not activate the row. Actions appear on hover, keyboard focus, and the selected file.

Standards and checks

Standards used

  • APG Tree View with role="tree", treeitem, and group.
  • WCAG 2.2 AA for focus-visible, name, and contrast.

Why decisions were made

  • Expand lives on the chevron; row activation opens the file. That matches file managers and keeps arrow-key expand separate from Enter.
  • Trailing menus are excluded from row activation so Delete cannot fire when the user meant to select the file.
  • Default appearance is flush. A boxed outline is opt-in so the tree can sit in a sidebar without a second border.

Success checks covered

  • Arrow keys, Home, and End move focus between rows.
  • Parent rows expose aria-expanded; checkboxes use aria-checked.
  • Each overflow action has its own accessible name.

References: APG Tree View, A11Y Project Checklist.
