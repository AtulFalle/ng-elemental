Tree

Hierarchical files-and-folders list. Project nested el-tree-item rows, or pass [nodes] for checkboxes, virtualization, lazy children, and load more.

Add to your project: npx @ng-elemental/cli add tree (requires icon, checkbox, and button)

Preview

Installation

Usage

The parent owns expanded and checked. Project leading media with elTreeLeading and row actions with elTreeActions. Nested el-tree-item children form the hierarchy.

Examples

Cascade checkboxes

Checking a folder checks descendants. A mixed folder shows indeterminate. The checked model stores subtree roots only.

Actions

Virtual

Set a max-height on el-tree. Virtual mode flattens expanded rows and requires [nodes] plus elTreeNodeDef.

{{ node.label }}

Lazy children and load more

Expand a node with hasChildren and no children to emit loadChildren. Set hasMore on a node to paginate its children.

{{ node.label }}

Root infinite scroll

Root-level paging is not built in. Compose Infinite Scroll around the tree.
