Tree

Hierarchical files-and-folders list. Project nested el-tree-item rows, or pass [nodes] for checkboxes, virtualization, lazy children, and load more.

Add to your project: npx @ng-elemental/cli add tree (requires icon, checkbox, and button)

Installation

Usage

The parent owns expanded and checked. Project leading media with elTreeLeading and row actions with elTreeActions. Nested el-tree-item children form the hierarchy.

Standards and checks

  • APG Tree View with role="tree", treeitem, and group.
  • Arrow keys, Home, End, and typeahead move focus between rows.
  • Parent rows expose aria-expanded; checkboxes use aria-checked.

References: APG Tree View, A11Y Project Checklist.
