Chip

Material Design 3 chips with Font Awesome start icons (checkmark or custom names) and an optional close icon at the end.

Assist With icon

Assist chips use native button semantics with visible label text as the accessible name. Handle actions via (clicked).

Prerequisites

  • Theme — design tokens from init (or add theme). See Installation §3.
  • Icon + Font Awesome — required for start/close icons. Install @fortawesome/fontawesome-free and import fontawesome.scss. See Icon setup.
