Accordion

Stacked expandable sections. The group owns which panels are open. Use variant="single" for one open panel, or variant="multiple" to keep several open. Put custom components in ng-template slots.

Add to your project: npx @ng-elemental/cli add accordion (requires icon)

Usage

Import the accordion, item, and content directive. Put panel markup in <ng-template elAccordionContent> so collapsed panels are not created. Optional title and subtitle templates replace the string headers with any HTML. Header actions go in [elAccordionActions]. They sit before the expand icon and do not toggle the panel.

Examples

Custom templates and header actions

Compose Icon, Chip, and Button in the header. Actions sit before the expand chevron. Add those components separately via the CLI. Clicks on elAccordionActions do not expand or collapse the panel.
