Autocomplete

Editable combobox with a filtered suggestion list. Keep query (what the user typed) separate from value (the committed option id). Compose Input chrome via prefix/suffix slots, and drop Empty State / Progress into status slots — Autocomplete does not invent its own spinner or empty copy.

Country @for (c of countries; track c.value) { {{ c.label }} }

Native input with role="combobox", aria-autocomplete="list", aria-expanded, aria-controls, and aria-activedescendant. Focus stays on the field while arrows move the active option. Escape closes without changing the committed value.

Installation

Registry dependencies: input and icon (default chevron). Add empty-state, progress, avatar, badge, label, or form-error only when your examples compose them.

  2. Update the import paths to match your project setup.

Usage

Filtering

With filter (default), typing hides non-matching options by label. Prefix an el-icon with elInputPrefix for a search affordance.

@for (c of countries; track c.value) { {{ c.label }} }

Filtering is client-side substring match on label || value. For remote data, set [filter]="false" and project only the results you fetched.

Async suggestions

Autocomplete never performs HTTP. Bind [(query)], set [loading], and project filtered items with [filter]="false". Compose progress and empty-state into the status slots.

@for (person of asyncResults(); track person.id) { {{ person.name }} }

aria-busy follows loading. Status content uses role="status" and is never an option. Rich rows are free-form projection inside el-autocomplete-item.

Slots and composition

Prefix/suffix re-project into ElInput. A custom suffix replaces the default chevron. Loading and empty accept an attribute node or ng-template with let-query.

@for (c of countries; track c.value) { {{ c.label }} }

Prefer existing El* widgets in slots over custom chrome. Templates win when both an attribute node and ng-template are provided for the same slot.

Disabled

India

Native disabled on the input. Panel cannot open.

Error and forms

Pair with el-label and el-form-error. Bind [(value)] for committed selection; use [value] / (valueChange) with Reactive Forms if needed. There is no ControlValueAccessor.

Country @for (c of countries; track c.value) { {{ c.label }} } Country is required

Error is not color-only: invalid border plus aria-invalid and a linked aria-describedby message.

Keyboard

Follows the WAI-ARIA editable combobox pattern (list autocomplete, manual selection). DOM focus stays on the input.

Standards

  • Standards used: WCAG 2.2 AA; WAI-ARIA Combobox Pattern (editable, list autocomplete).
  • Why: Select is select-only. Autocomplete needs an editable field, query vs value, and activedescendant while typing.
  • Success checks: named combobox; keyboard-only select; Escape restores query; outside click closes; disabled not operable; loading exposes busy; empty/loading are status, not options; focus ring on keyboard; reduced motion honored.
  • References: APG Combobox, List autocomplete example.
