Install your way

Use the CLI yourself, or point Cursor and Claude at the hosted MCP server — both land the same source in your project.

  1. init — creates elemental.json and theme tokens
  2. add — copies component TypeScript, HTML, and SCSS
  3. import — use the copied files like any local component
