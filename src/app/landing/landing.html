Install with the CLI

@ng-elemental/cli copies component source files directly into your Angular project. Run init once to configure the output directory and install theme tokens, then add any component by name.

1
init — creates elemental.json, installs theme tokens and sets up your component directory
2
add <component> — copies TypeScript, HTML, and SCSS into your project
3
import & use — import the copied file like any local Angular component

AI agents use the MCP server

@ng-elemental/mcp exposes a Model Context Protocol endpoint so Cursor, Claude Desktop, and other AI coding tools can list, inspect, and install NgElemental components on behalf of a developer — no terminal commands needed.

Point your MCP client at https://ng-elemental.vercel.app/mcp — no local install required.
